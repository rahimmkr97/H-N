Cloud Sync

Connect a free Firebase project once, then sign in with the same account on your iPhone and your desktop to share one live database between them — materials, factory settings, orders and production all included.
One-time setup (about 10 minutes):
1. Go to console.firebase.google.com and create a free project.
2. Open Build → Authentication → Sign-in method and enable Email/Password.
3. Open Build → Firestore Database, click Create database (production mode is fine), then open its Rules tab and paste this, then click Publish: rules_version='2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid}/{doc=**} { allow read, write: if request.auth != null && request.auth.uid == uid; } } } 4. Open Project settings → General, scroll to "Your apps", click the </> (Web) icon to register a web app, and copy the firebaseConfig object it shows you.
5. Paste that config below on this device, then repeat steps 4–5 on your other device using the exact same config.

Calculation basis

Film GSM = thickness (µm) × density (g/cm³).
Lamination glue is added once for each interface: Duplex = 1 interface, Triplex = 2.
Printed film adds the entered ink GSM.
Roll length from diameter uses the annulus formula and the total physical film thickness.
Production costing applies the entered waste percentage to material, ink and glue consumption.
