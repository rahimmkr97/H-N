Cloud sync

Connect your own Firebase project once, then sign in with the same account on every device to share one live database: materials, factory settings, orders and production data.
First-time setup instructions 1. Go to console.firebase.google.com and create a free project.
2. Open Build → Authentication → Sign-in method and enable Email/Password.
3. Open Build → Firestore Database, click Create database, then open its Rules tab, paste this and click Publish: rules_version='2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid}/{doc=**} { allow read, write: if request.auth != null && request.auth.uid == uid; } } } 4. Open Project settings → General, scroll to "Your apps", click the </> (Web) icon to register a web app, and copy the firebaseConfig object it shows.
5. Paste it below on this device, then repeat on your other devices with the exact same config.

Calculation basis

Film GSM = thickness (µm) × density (g/cm³).
Lamination glue is added once for each interface: Duplex = 1 interface, Triplex = 2.
Printed film adds the entered ink GSM.
Roll length from diameter uses the annulus formula and the total physical film thickness.
Production costing applies the entered waste percentage to material, ink and glue consumption.
